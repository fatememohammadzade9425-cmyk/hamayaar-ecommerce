# هم‌عیار هوشمند (HAMAYAR)
پروژه درس تجارت الکترونیکی — دانشگاه یزد

## ایده
بازارگاه چندفروشندگی طلا، نقره، سکه و شمش با سه تمایز پیشنهادی: مقایسه‌گر شفاف اجزای قیمت، تجمیع تقاضای خرید گروهی، و شناسنامه اطلاعاتی فروشنده/محصول. این تمایزها فرضیه محصول‌اند و باید با آزمون بازار سنجیده شوند.
.

## قابلیت‌های قابل آزمون این نسخه
- جست‌وجو و فیلتر دسته‌بندی و مرتب‌سازی
- ثبت درخواست استعلام از روی کالا
- مشاهده و تغییر وضعیت آزمایشی درخواست
- محاسبه‌گر اجزای قیمت با اعتبارسنجی ورودی
- ثبت تقاضای خرید گروهی
- ذخیره درخواست‌ها و تقاضاها در LocalStorage و حفظ پس از Refresh

## محدودیت‌ها
این نسخه MVP آموزشی سمت کاربر است. داده و قیمت ساختگی‌اند. LocalStorage پایگاه داده مرکزی یا امن نیست. ورود واقعی، نقش‌های امن، پنل فروشنده، قیمت زنده، احراز اصالت، پرداخت و ارسال واقعی وجود ندارد.
